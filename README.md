# Skills

Skills para agentes de IA de Agustín Velásquez.

## Text Hierarchy

Define la dirección visual y la densidad de contenido con el usuario y ajusta la jerarquía tipográfica al espacio real de cada componente. Complementa `frontend-design` y también funciona por separado.

- Consulta la intención del diseño y si se pueden simplificar los textos.
- Usa referencias visuales para calibrar minimalismo y maximalismo.
- Ajusta tamaños, interlineados y espacios conservando información esencial.
- Incluye criterios de revisión responsive y legibilidad.

### Instalar

```bash
npx skills add agustinvelasquez/skills --skill text-hierarchy
```

### Usar

```text
Usá $text-hierarchy para simplificar estas tarjetas y mejorar su jerarquía.
```
